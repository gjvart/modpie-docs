# Settings & Reference Overview

<div className="hero-badge-container">
  <span className="badge badge--secondary">Settings & Reference</span>
</div>

Welcome to the **Settings & Reference** section.

Modpie is designed to work smoothly out of the box with sensible defaults. However, every artist models differently—whether you prefer high mouse sensitivity for rapid gestures, custom HUD positioning, or docked panels instead of floating popups, you have complete control over how Modpie behaves.

This section covers Modpie's full preferences menu, how it works with custom Geometry Nodes modifiers, and how the viewport panel intelligently manages screen focus while you model.

---

## What You'll Find in This Section

### 1. [Preferences & Configuration Guide](preferences.md)
A complete tour of every setting available in **Edit ▸ Preferences ▸ Add-ons ▸ Modpie**:
- **Interactive Drag**: Customize mouse drag sensitivity, object scale multipliers, HUD screen offsets, guidelines, and status message durations.
- **Modpie Panel**: Switch between floating cursor popups and docked sidebar panels, set your default panel width, and configure auto-activation behavior.
- **Shortcuts & Conflict Detection**: Rebind any hotkey and let Modpie's real-time conflict detector warn you if a shortcut clashes with native Blender tools.

### 2. [Geometry Nodes Modifiers](geometry-nodes.md)
How Modpie automatically inspects and displays input sockets on custom Geometry Nodes modifiers and official assets (like Blender 5.0+ Curve to Tube). You can tweak procedural values, curve profiles, and resolution sliders right inside the viewport panel without switching to the modifier properties tab.

### 3. [Viewport Panel Behavior](panel-behavior.md)
How the panel keeps your 3D view clean by automatically stepping out of the way. When you start an interactive drag or adjustment, the panel hides instantly so you have an unobstructed view of your model, and smoothly returns when you're done.
