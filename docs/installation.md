# Installation & Upgrading

Installing Modpie takes less than a minute using Blender's standard Extension and Add-on system.

---

## Requirements

Before installing, ensure you have:
- **Blender 4.5, 5.0, 5.1, 5.2+ (Tested & Optimized)**, or 4.2 LTS / 4.3 / 4.4
- The Modpie `.zip` file (`modpie-*.zip` or `modpie-plus-*.zip`)

---

## Installation Steps

1. **Open Blender Preferences**:  
   In Blender, navigate to **Edit ▸ Preferences ▸ Add-ons** (or **Get Extensions ▸ Repositories / Add-ons**).

2. **Install from Disk**:  
   Click the drop-down menu icon (<kbd>▾</kbd>) at the top right of the Preferences window and select **Install from Disk...**

3. **Select Zip File**:  
   Locate and choose your downloaded `modpie-*.zip` (or `modpie-plus-*.zip`) file.

4. **Enable the Add-on**:  
   Search for **Modpie** in the search box and enable the checkbox next to **3D View: Modpie**.

---

## Seamless Upgrading to Modpie Plus

When upgrading from **Modpie Free** to **Modpie Plus**:
1. Do **not** uninstall Modpie Free.
2. Open **Edit ▸ Preferences ▸ Add-ons** and select **Install from Disk...**
3. Choose the `modpie-plus-*.zip` file.
4. Blender updates the files in place.

:::success Settings Preserved
Because both versions share the identical internal extension ID `modpie`, all your configured pie slots, custom labels, arrival values, and keymaps are 100% preserved.
:::
